# AromaBlend: Custom Coffee Brew Ratio & Extraction Profiler

## Purpose
AromaBlend is a precision coffee brewing calculator and flavor profiler designed for specialty coffee lovers and baristas. It removes guesswork by calculating exact coffee-to-water ratios, extraction percentages, Total Dissolved Solids (TDS), brew times, and dynamic tasting notes.

## Features
- **Multiple Brew Methods:** Pre-configured ratios for Pour Over (V60), Chemex, Espresso, Aeropress, and French Press.
- **Advanced Parameter Controls:** Fine-tune coffee weight, water temperature, roast profile, and grind size.
- **Real-Time Extraction Metrics:** Computes brew ratio, estimated brew time, extraction yield %, and strength (TDS) with automated status feedback (Optimal, Under-extracted, Over-extracted).
- **Flavor Profile Radar Chart:** Visualizes expected flavor attributes (Acidity, Sweetness, Body, Bitterness, Clarity) on an interactive canvas polygon.
- **Step-by-Step Pour Guide:** Generates custom pouring and steeping instructions tailored to your chosen method.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Adjust parameters and click **Calculate Brew Profile** to view your customized extraction metrics and guide.

## Technology Stack
- Pure vanilla HTML5, CSS3, and modern JavaScript (ES6+).
- HTML5 Canvas for dynamic radar chart visualization.
- Zero external dependencies, build tools, or network requests.
